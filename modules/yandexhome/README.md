# Yandex Home

Приватный навык умного дома Яндекса для MajorDoMo: OAuth 2.0, Provider Adapter API и редактор устройств в админке.

Документация для базы знаний админки лежит в [`docs/`](docs/README.md). Она появляется в разделе «База знаний» только при установленном модуле.

- [Обзор](docs/README.md)
- [Настройка и публикация навыка](docs/setup.md)
- [Устройства и умения](docs/devices.md)
- [API и внутреннее устройство](docs/api.md)
- [Диагностика](docs/troubleshooting.md)

- `/modules/yandexhome/authorize.php`
- `/modules/yandexhome/token.php`
- `/modules/yandexhome/smarthome.php`
