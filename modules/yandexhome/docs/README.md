# Yandex Home — обзор

Модуль превращает MajorDoMo в **приватный навык умного дома Яндекса**. Он реализует OAuth 2.0 для связки аккаунтов и Provider Adapter API: Яндекс присылает запросы к трём вебхукам модуля, а модуль читает и пишет свойства объектов MajorDoMo.

Документация модуля лежит рядом с кодом в `modules/yandexhome/docs/`. Она появляется в базе знаний админки только пока модуль установлен.

## Что умеет модуль

- discovery — отдаёт Яндексу список устройств, их типы и умения;
- query — возвращает текущие значения привязанных свойств объектов;
- action — включает, выключает и настраивает устройства через `setGlobal()`;
- reportable — отправляет изменения свойств в Яндекс без запроса Алисы (если настроены токен и ID навыка);
- поддерживает 60+ типов устройств и 60+ умений: свет, розетки, термостаты, медиа, датчики, счётчики, шторы, камеры и другие.

## Быстрый старт

1. Откройте **Устройства → Yandex Home → Настройки**.
2. Придумайте логин и пароль для связки аккаунтов. Это отдельная учётная запись, не пароль администратора MajorDoMo.
3. Сгенерируйте **OAuth2 ID** и **OAuth2 KEY** кнопками рядом с полями и сохраните настройки.
4. Опубликуйте три вебхука из карточки «Вебхуки навыка» в интернете по HTTPS.
5. Создайте приватный навык категории **Умный дом** в [консоли Яндекс Диалогов](https://dialogs.yandex.ru/developer/skills/) и укажите вебхуки, ID и KEY.
6. В приложении Яндекс выберите навык, нажмите **Объединить аккаунты** и введите логин/пароль из шага 2.
7. Добавьте устройства в модуле и привяжите их умения к свойствам объектов.

Подробные шаги — в [настройке](setup.md), работа с устройствами — в [устройствах](devices.md).

## Требования

- публичный IP или туннель, доменное имя и валидный HTTPS-сертификат;
- три вебхука доступны из интернета **без** запроса логина и пароля reverse proxy;
- PHP-расширения `pdo_mysql` и `curl`;
- настроенные объекты и свойства MajorDoMo, которыми реально управляют ваши устройства или сценарии.

## Совместимость

Модуль сохраняет прежние таблицы (`yandexhome_devices`, `yandexhome_oauth`), адреса вебхуков и формат `TRAITS`/`CONFIG`. Старые устройства и токены продолжают работать после обновления. Админка переведена на общую дизайн-систему, а редактор умений — на vanilla JS без Bootstrap 3 и jQuery.
