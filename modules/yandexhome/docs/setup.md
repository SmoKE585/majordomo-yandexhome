# Настройка и публикация навыка

## 1. Настройки модуля

Откройте **Устройства → Yandex Home → Настройки**.

| Поле | Назначение |
| --- | --- |
| Логин пользователя | Логин, который вы введёте в приложении Яндекс при объединении аккаунтов. |
| Пароль пользователя | Пароль для той же связки. Хранится в настройках модуля. |
| OAuth2 ID | Идентификатор приложения в связке аккаунтов Яндекса. |
| OAuth2 KEY | Секрет приложения. |
| Токен Яндекс Диалогов | Нужен только для reportable-уведомлений. |
| ID навыка | Нужен только для reportable-уведомлений. |
| Автономный режим | Запрещает запись в свойства объектов. |
| Отладка DebMes | Подробный журнал модуля. |

Кнопки со стрелками рядом с **OAuth2 ID** и **OAuth2 KEY** генерируют случайные значения в формате UUID. После изменения KEY обновите связку в консоли Яндекса.

## 2. Вебхуки

Модуль публикует три адреса:

| Назначение | Адрес |
| --- | --- |
| URL авторизации | `/modules/yandexhome/authorize.php` |
| URL токена | `/modules/yandexhome/token.php` |
| Endpoint навыка | `/modules/yandexhome/smarthome.php` |

В карточке «Вебхуки навыка» показаны полные адреса с текущим доменом и кнопки копирования.

Требования к публикации:

- HTTPS с валидным сертификатом;
- адреса доступны из интернета;
- reverse proxy не требует логин и пароль на этих трёх адресах;
- `authorize.php` и `token.php` должны принимать POST, `smarthome.php` — POST и GET.

Проверка снаружи:

```bash
curl -I https://example.com/modules/yandexhome/token.php
curl -I https://example.com/modules/yandexhome/smarthome.php
```

`401` от самого модуля на `token.php` без параметров — нормально. Ошибка `401` от reverse proxy означает, что вебхук закрыт basic auth и Яндекс не сможет им воспользоваться.

## 3. Приватный навык в Яндекс Диалогах

1. Откройте [консоль разработчика](https://dialogs.yandex.ru/developer/skills/) и войдите под нужной учётной записью.
2. В настройках создайте **связку аккаунтов**:
   - идентификатор приложения — OAuth2 ID из модуля;
   - секрет приложения — OAuth2 KEY;
   - URL авторизации — `https://<домен>/modules/yandexhome/authorize.php`;
   - URL токена и URL обновления токена — `https://<домен>/modules/yandexhome/token.php`.
3. Создайте навык типа **Умный дом**.
4. Укажите Endpoint URL `https://<домен>/modules/yandexhome/smarthome.php`.
5. Включите приватность «Не показывать в каталоге», заполните описание и иконку.
6. Отправьте навык на модерацию и опубликуйте.

## 4. Объединение аккаунтов

В приложении Яндекс откройте **Умный дом → Добавить устройство → Популярные производители**, выберите свой навык и нажмите **Объединить аккаунты**.

Откроется страница `authorize.php`. Введите логин и пароль из настроек модуля и подтвердите доступ. После этого нажмите **Обновить список устройств** — в приложении появятся устройства, добавленные в модуле.

При добавлении, изменении или удалении устройства в модуле Яндекс нужно синхронизировать повторно. Если настроены токен и ID навыка, модуль отправляет discovery-callback автоматически.

## 5. Reportable-уведомления

Reportable позволяет модулю самому сообщать Яндексу об изменении свойства, не дожидаясь запроса Алисы.

Чтобы включить:

1. Получите OAuth-токен Яндекс Диалогов для Notification API.
2. Укажите токен и ID навыка в настройках модуля.
3. В карточке устройства включите **Reportable** у нужных умений.
4. Нажмите **Проверить callback** в настройках — модуль отправит discovery-callback и покажет HTTP-код.

Если токен или ID не заданы, модуль отдаёт `reportable=false` и продолжает работать в режиме опроса.
