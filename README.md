# Yandex Home для MajorDoMo

Приватный навык умного дома Яндекса для MajorDoMo: OAuth 2.0 для связки аккаунтов и Provider Adapter API для управления устройствами через Алису.

Модуль принимает запросы платформы Яндекс (`discovery`, `query`, `action`, `unlink`), читает и записывает свойства объектов MajorDoMo и при необходимости отправляет reportable-уведомления в Яндекс.

## Возможности

- 60+ типов устройств и 60+ умений: свет, розетки, термостаты, медиа, техника, шторы, замки, датчики, счётчики;
- привязка каждого умения к своему объекту и свойству MajorDoMo;
- преобразование значений (1/0 → on/off, opened/closed, detected, leak и другие пресеты, а также своя таблица);
- диапазоны Min/Max/Step для яркости, температуры, громкости и других `range`-умений;
- Split для `on_off` и reportable-уведомления;
- видео-поток камеры (HLS) через привязанное свойство;
- автономный режим «только чтение»;
- журнал DebMes и кнопка проверки discovery-callback;
- админка на общей дизайн-системе MajorDoMo, без Bootstrap 3 и jQuery;
- документация для встроенной базы знаний в `modules/yandexhome/docs/` — она видна в админке только при установленном модуле.

## Требования

- публичный IP (или туннель), доменное имя и валидный HTTPS-сертификат;
- три вебхука доступны из интернета **без** запроса логина и пароля reverse proxy;
- PHP-расширения `pdo_mysql` и `curl`;
- зарегистрированный приватный навык категории «Умный дом» в [Яндекс Диалогах](https://dialogs.yandex.ru/developer/skills/).

## Установка

1. Установите модуль через «Маркет дополнений» MajorDoMo.
2. Откройте **Устройства → Yandex Home → Настройки**.
3. Задайте логин и пароль для связки аккаунтов, сгенерируйте OAuth2 ID и KEY.
4. Опубликуйте вебхуки:
   - `/modules/yandexhome/authorize.php`;
   - `/modules/yandexhome/token.php`;
   - `/modules/yandexhome/smarthome.php`.
5. Создайте приватный навык «Умный дом» в консоли Яндекс Диалогов и укажите те же ID, KEY и вебхуки.
6. Объедините аккаунты в приложении Яндекс.
7. Добавьте устройства в модуле и привяжите их умения к свойствам объектов.

Подробная инструкция — в [docs/setup.md](docs/setup.md).

## Совместимость

Формат таблиц `yandexhome_devices` и `yandexhome_oauth`, адреса вебхуков и формат `TRAITS`/`CONFIG` сохранены. Старые устройства и токены продолжают работать после обновления.

## Структура

```
modules/yandexhome/          PHP-модуль, вебхуки, каталог умений, docs/
templates/yandexhome/        шаблоны админки
public/assets/modules/yandexhome/  page-only CSS/JS
public/assets/img/modules/yandexhome.png
img/modules/yandexhome.png   иконка для старых ядер
```
